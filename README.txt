ALVES Finance — versão para WEB

Esta versão foi preparada para funcionar como site (HTTP/HTTPS), e não apenas como arquivo local.

ARQUIVOS:
- index.html
- logo.jpg
- manifest.webmanifest
- sw.js

COMO PUBLICAR:
1. Extraia este ZIP em uma pasta.
2. Publique a pasta em um serviço de hospedagem estática, como o Netlify Drop.
3. Depois de publicada, abra a URL do site no Chrome do celular.
4. Os botões de navegação e os lançamentos funcionarão como uma aplicação web.
5. Você pode adicionar o site à tela inicial do celular.

IMPORTANTE:
Os dados financeiros continuam salvos no navegador (localStorage). Se o navegador/aplicativo for limpo, os dados locais podem ser apagados.
